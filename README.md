- 미야코지마 섬 공연
- 미야코지마 햄버거 존
- 미야코지마 바닷가와 스노클링
- 발리 2026년 3월 19일: 새벽 대나무 리조트 도착
- 발리 2026년 3월 20일: 정글 인피니티 풀
- 발리 2026년 3월 21일: 절벽 선셋 디너
- 발리 2026년 3월 22일: 야자수 정원의 마지막 노을
- 2026년 4월 5일: 반려견과 벚꽃 나들이
- 2026년 6월 3일: 반려견과 홍천 아트 갤러리

## 독립 구조

- `index.html`: 화면, 스타일, 캐릭터 동작을 모두 포함한 프로젝트 루트 진입 파일
- `assets/`: 여행 배경과 예찌·한원 캐릭터 이미지
- 외부 패키지나 빌드 과정 없음

이 폴더를 그대로 별도 GitHub 저장소의 루트로 사용하면 GitHub Pages에서 실행할 수 있습니다. 기존 Stock Dashboard와의 경로 의존성은 제거되어 있습니다.

## 로컬 확인

프로젝트 폴더에서 정적 서버를 실행합니다.

```powershell
python -m http.server 4173
```

- 기본 화면: `http://localhost:4173/`
- 미야코지마: `http://localhost:4173/#miyakojima`
- 발리: `http://localhost:4173/#bali`
- 벚꽃: `http://localhost:4173/#cherry`
- 홍천: `http://localhost:4173/#hongcheon`
